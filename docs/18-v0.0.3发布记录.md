### CI 初始化修正

已读取本次源码运行 `37612569688` 的实际失败日志：setup-android 默认 packages 为 `tools platform-tools`，sdkmanager 报 `Failed to find package 'tools'`，后续 Gradle 尚未执行。工作流显式设置 `packages: platform-tools`，后续仍安装固定 platform/build-tools 组件。该修正不改变业务代码；最终 APK 从包含此项修正的源码提交构建。

发布材料编码复核：含中文的清单保持 UTF-8 BOM；ASCII 的 SHA256SUMS 使用无 BOM UTF-8，供标准 sha256sum 校验。新增对应回归后，发布工具共 16 项通过。

标准工具实测还发现 Windows 默认文本换行会令校验和中的文件名带 CR。发布输出统一为 LF，并增加字节级换行断言，保持跨平台校验和可用。
