# 播放页遥控器焦点与切集修复

记录：2026-10-11 14:07。用户授权分析并修复播放页上一集/下一集不可选择、下一集确认反而暂停的问题。目标为Android4.1+/API16独立工程，基线75da088；不修改现代Compose工程，不自动发布版本、推送或替换OTA。

## 问题与原因

- 首次记录时间：2026-10-11 13:54；症状：方向键无法到达全部控制按钮，确认下一集却执行播放/暂停。
- `PlayerActivity.dispatchKeyEvent`在ACTION_DOWN全局截获CENTER/ENTER并调用togglePlayPause，不检查焦点；左右同样全局seek。因此布局虽有上下集OnClick，遥控器不会调用它们。
- `startPlayback`每次重新创建播放器后都请求暂停按钮焦点，进一步破坏连续切集操作。
- 修复前新增两项实际Activity按键流程回归均失败，确认不是按钮所需的切集监听缺失；原始XML证据保存在`.gradle/playback-remote-fix/before/PlayerFlowTest.xml`。未获取投影ADB日志。
- 临时方式：旧版可用数字1/3、媒体上一首/下一首切集。

## 方案与文件用途

比较仅添加XML焦点指向和分离按键所有权两种方式：XML不能绕过Activity的全局拦截，选择播放页统一按键入口、按当前层级与焦点分派，继续禁用ExoPlayer内置控制器，不让播放器组件抢电视输入。

- `app/src/main/java/com/tvbox/android44/feature/player/PlayerActivity.java`：控制栏可见时确认激活焦点按钮；左右只在进度条焦点下seek，否则导航；上下进入进度条/返回按钮。错误层优先激活重试/返回，以其自己的findFocus读取焦点。两半事件均消费，动作repeat不重复切集/暂停/返回。切集和换线保留当前控制焦点。
- `app/src/main/java/com/tvbox/android44/feature/player/PlayerControllerView.java`：明确按钮顺序、边界停留、最近按钮恢复、只点击当前控件；焦点和按键刷新5秒隐藏计时；请求焦点完整滚动到可见区。保留普通按钮的触摸属性，避免首击只聚焦不点击；Android原生负责方向键离开触摸模式，说明见[官方View文档](https://developer.android.com/reference/android/view/View.html#touch-mode)。
- `app/src/main/res/layout/activity_player.xml`：HorizontalScrollView承载按钮行，宽度足够时居中，窄屏/大字体时滚动显示完整按钮。
- `app/src/test/java/com/tvbox/android44/feature/player/PlayerFlowTest.java`：新增API16/19/23/28完整按下/抬起回归，检验实际集索引、播放意图、焦点保留、长按、进度条、首末集、错误层及快捷键；之前缓冲seek冷却测试改为明确聚焦进度条。

## 操作规则

1. 控制栏隐藏时按方向键显示它，初始焦点为播放/暂停；隐藏时确认保持原播放暂停行为并显示控制栏。
2. 按钮行左右依次为上一集、播放/暂停、下一集、倍速、换线、退出；确认只执行所选动作。首/末集点击对应边界按钮提示，不绕回，也不暂停。
3. 上键进入进度条，左右各seek10秒，下键返回此前按钮。进度条确认不误触播放/暂停。
4. 数字1/3、NUMPAD1/3、媒体上一首/下一首仍切集；专用MEDIA_PLAY_PAUSE不受焦点影响；MENU仍循环倍速。
5. 单次按下及抬起不重复动作；长按确认、切集、菜单、返回只执行首次，方向键允许连续移动。BACK先关错误层，再关控制栏，最后退出；抬起不跳过层级。
6. 切集/换线后保持按钮焦点，避免接着确认却落到暂停。错误层方向与确认只操作重试/返回，不激活其后控制栏。
