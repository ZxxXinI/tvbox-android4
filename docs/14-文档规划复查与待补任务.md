## 实现依据与行为

### P1-01：播放器返回详情

[PlayerActivity](../app/src/main/java/com/tvbox/android44/feature/player/PlayerActivity.java) 与 [DetailActivity](../app/src/main/java/com/tvbox/android44/feature/detail/DetailActivity.java) 使用同一 `REQUEST_PLAYBACK=2001`。播放器退出通过结果 Intent 回传影片、线路、集和进度快照；详情更新当前选择与继续播放按钮，并在布局完成后恢复当前集焦点。

回归刻意阻塞磁盘队列，验证尚未落盘时仍能得到最新状态。原复查中的请求编号不一致和缺少状态回传已修复。

### P1-02：缓冲判定与播放器流程

BUFFERING 事件和播放页 500 毫秒进度轮询共同检查持续缓冲；READY 结束本次缓冲窗口。用户暂停按 `playWhenReady` 判断，缓冲引起的 `isPlaying=false` 不再被当作暂停。seek 冷却、关闭自动换线、同集匹配、尝试去重和最终错误继续有效；页面停止释放播放器与轮询。

自动化使用可控 ExoPlayer 事件与假时钟，覆盖页面接入。实际慢流、坏线、设备解码和播放时延仍需物理盒子验证。

### P1-03：线路健康记录

[HealthStore](../app/src/main/java/com/tvbox/android44/data/local/HealthStore.java) 在应用管理的顺序磁盘队列初始化、写入和清空；播放决策只读取内存快照，统计页异步等待队列。写成功后才发布新快照，清空失败明确提示。保留 30 天/300 条约束，过滤坏记录，包含慢缓冲时间，计数溢出不会变负。

回归覆盖首次加载不阻塞调用者、初始化与操作有序、独立快照、重启、损坏备份、过期、上限和写失败；设置页晚到回调不作用于隐藏或重建后的 View。

### P2-01：历史恢复

历史入口把记录快照传入详情；普通详情的历史读取离开主线程。首次详情失败且旧地址是合法 `http/https` 时提示用户，可直接临时播放，并保留原影片和集数信息。共享 [PlaybackSelection](../app/src/main/java/com/tvbox/android44/domain/playback/PlaybackSelection.java) 依次匹配线路 ID、名称、可播放默认线路，再按集标题优先、合法索引兜底。

接近片尾使用 `HISTORY_END_RESTART_RATIO`；有下一集时从下一集 0 开始，否则最后一集从头。播放器返回详情及 Activity 状态恢复不重复应用片尾跳集策略。

### P2-02：媒体类型

[VodMediaSources](../app/src/main/java/com/tvbox/android44/feature/player/VodMediaSources.java) 只检查 URL path 的 `.m3u8` 后缀，查询参数中的同名文字不会误判。它观察真正播放请求的 Content-Type，不发送额外探测；无扩展名媒体先由 Progressive 提取器尝试，HLS MIME 或明确格式解析错误允许切换类型一次，HTTP 错误不盲目重试。

格式回退与换线尝试分别计数，失败后进入原有受控换线/错误流程。自动化验证创建和错误恢复策略；真实 MP4、标准 HLS、无扩展名 HLS 出画出声待设备验收。

### P2-03：启动检查更新

[MainActivity](../app/src/main/java/com/tvbox/android44/feature/main/MainActivity.java) 读取启动开关及清单 URL，复用更新仓库；开关关闭或 URL 为空不请求。进程内完成检查后节流 15 分钟，同一版本只提示一次；旧 Activity 取消不能释放新检查。检查失败静默，页面停止取消。

发现新版本仅询问是否前往设置查看说明；下载、安装和未知来源授权仍由用户操作触发。手动检查不受启动节流限制。进程重启后允许重新检查和提示。

### P2-04：扫码会话

[ConfigHttpServer](../app/src/main/java/com/tvbox/android44/feature/settings/ConfigHttpServer.java) 固定会话模式，只绑定选中的站点本地 IPv4 地址；有多个地址时电视端让用户选择。随机 token 有效 5 分钟，调度器主动关闭监听与已接收连接；错误 token、非法表单及保存失败统一最多 5 次。

排队提交执行前检查当前会话，关闭后不会保存或影响新会话。成功消耗 token，先向手机返回保存结果，再关闭服务与电视弹窗；即使手机断开也释放会话。表单按 UTF-8 字节长度读取并限制大小，HTTP no-store，完整 Key 不回显。

真实回环 Socket 回归覆盖成功后重用、到期主动关闭、旧提交、重新打开不同模式、非法请求、端口占用及连续开关 10 次。手机二维码扫描、实际局域网路由和盒子网络接口仍待设备验收。

### P2-05：AI 请求与生命周期

[AiClient](../app/src/main/java/com/tvbox/android44/data/remote/AiClient.java) 规范化提供方 URL，避免重复追加 `/chat/completions`；默认连接/读/写为 30/45/20 秒，整体请求上限 60 秒。先处理 401/403/429 等 HTTP 状态，再检查响应结构；空或异常内容返回可操作提示，不把服务端原文显示给用户。

[RecommendRepository](../app/src/main/java/com/tvbox/android44/data/repository/RecommendRepository.java) 使用单任务完成回调，取消后丢弃已排队结果；推荐页使用请求代次和 View 生命周期保护。相同问题加载中不重复请求，改问题会取消旧请求；错误 Key 等失败保留上一批结果并引导配置；隐藏或销毁页面取消请求，重建后可再次提交；结果不会抢导航焦点。API 23 麦克风拒绝/授予、无语音服务及销毁后语音回调有回归。

测试只使用本地假服务和测试 Key。四提供方的真实配额、实际模型返回与系统语音服务可用性需按设备/外部服务验收记录。

### P3-01：文案与列表

布局文字统一引用 `strings.xml`，播放提示、详情进度、推荐状态和设置当前值使用格式资源。分类/线路、选集和推荐列表增加稳定 ID 与 DiffUtil，选择变化只更新受影响项，点击读取当前位置；推荐去重和重排保持当前卡片焦点。既有首页、搜索和历史的焦点回归继续运行。

本轮 Debug/Release 各 181 项回归通过，Lint 0 错误，警告从 126 降至 44，布局 HardcodedText 为 0。没有提高 minSdk 或新增关闭 Lint 来通过检查。剩余布局、资源及保留模块的建议列在验证报告；裁切、字号与遥控器视觉焦点以实际电视结果为准。
