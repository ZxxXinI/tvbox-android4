# 设置页遥控器焦点顺序修复

记录时间：2026-10-11 17:33（Asia/Shanghai）
状态：本地源码已修改；自动化验证通过；目标设备验收由用户完成；未提交、未推送、未发布。

## 现象

进入设置页后按遥控器方向下，焦点会跳过某些控件，顺序不稳定。用户观察到可以先按上到顶部“历史(1)”，再按下落到“当前视频源：XX”，以此打开视频源切换列表。

## 根因

设置页只在首次显示时通过 `FocusUtils.firstFocusable()` 按 XML 子项顺序选择首个控件；布局没有为各按钮配置 `nextFocusUp/Down/Left/Right`。后续按键因此交给 Android FocusFinder 根据控件矩形、距离及重叠方向推算目标。设置页同时混合了整行按钮、单控件行和多列按钮，焦点结果会受当前位置、字体与屏幕几何影响，所以方向下表现为跳项。

## 修复

- `SettingsFragment.configureRemoteFocus()` 明确设置所有可见操作控件的四向焦点邻居。
- 上下按内容区行序移动：外观 → 当前视频源 → 源管理/扫码 → AI 提供方 → Key → AI 扫码 → 播放管家 → 更新。
- 左右只在同一行按钮间移动；单控件行与左右/下边界停留，不让系统几何搜索跨到其他行。
- 顶部“设置”导航在设置页可见时向下连接到页面首项，隐藏或销毁设置页时清除该跨页链接。
- 电视/平台直播扩展服务原本为 `gone`，不加入焦点映射，焦点不能进入隐藏控件。
