# v0.0.5 发布记录：播放页遥控器修复

用户于2026-10-11授权发布上一轮已完成的播放器遥控器修复。新版本TVBox4.1+ / v0.0.5 / code5，最低Android 4.1/API16，包名`com.tvbox.android44`；沿用v0.0.4原签名及稳定OTA地址。

## 更新内容

- 控制栏显示时，方向键按顺序浏览上一集、播放/暂停、下一集、倍速、换线和退出；确认仅激活焦点操作。
- 上键进入进度条，左右10秒快退/快进，下键回到之前按钮。专用播放/暂停键、数字键、媒体上一首/下一首及菜单功能保留。
- 修复切集/换线后焦点被强制移回播放/暂停，避免连续操作误暂停；长按与抬起不重复执行。
- 窄屏按钮栏可滚动完整显示；错误提示页的确认和方向只控制重试/返回。

完整根因、文件用途和回归范围见 [播放器遥控器修复记录](21-播放遥控器焦点与切集修复.md)。

## 版本/签名/OTA

- 0.0.4/code4 → **0.0.5/code5**；包名和原证书保持一致，可覆盖升级。
- OTA继续使用`https://github.com/ZxxXinI/tvbox-android4/releases/latest/download/update.json`，最新版清单指向本次Release。
- 清单APK下载后校验大小和SHA-256，再由Android系统安装器处理；不是静默安装。API26+系统可能要求允许安装未知应用。
- 已装原签名0.0.4正式包或同签名0.0.4测试包都可检查更新。覆盖安装保留应用数据；不要卸载后重装。

Release构建使用原签名并成功完成；实际包名`com.tvbox.android44`、名称TVBox4.1+、版本0.0.5/code5、minSdk16、targetSdk28，运行时不可调试。最低API16要求的v1/v2签名均有效，证书SHA-256为`d507b831ebd7af498c550d0e24b84d1a10f218132ec9e6ce4c43d19f15c1e2d6`，与v0.0.4完全一致。此前播放专项Debug/Release各86项及Lint结果见[修复记录](21-播放遥控器焦点与切集修复.md)；版本递增发布时未重跑测试，也未触发CI。Windows五项存储失败历史保持原记录。屏幕、实际媒体解码与投影遥控器还需设备验收。
