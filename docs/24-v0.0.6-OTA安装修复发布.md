# v0.0.6 发布记录：OTA 安装器与保存回退

发布日期：2026-10-11 15:36（Asia/Shanghai）  
版本：TVBox4.1+ / `0.0.6` / versionCode `6`  
兼容范围：Android 4.1+ / minSdk 16，targetSdk 28  
状态：已设为 GitHub Latest；设备安装器和保存回退仍待用户验收。

## 更新内容

- OTA APK 改用安装专用 Intent，避免通用 `ACTION_VIEW` 把安装请求交给“打开方式”选择器中的无关应用。
- 缺少“安装未知应用”权限时提供“保存”选项，把已经完成大小/SHA-256 校验的 APK 复制到公共 `Download/TVBox/`，供用户手动安装。
- Android 10+ 使用 MediaStore；Android 4.1–9 使用公共下载目录，并按系统版本处理旧式存储权限。保存不删除应用内下载源文件。
- 沿用 v0.0.5 的签名证书；保留 v0.0.5 Release，并递增至 v0.0.6/code6，使现有 code5 安装能够发现 OTA 更新。

## 自动化与构建

- OTA 专项 `UpdateRepositoryTest`：18 项通过，0 失败。
- `lintRelease`、`assembleRelease`：成功。
- 全量 Debug 测试实际运行 396 项，5 项 Windows 存储相关测试失败（`HealthStoreTest` 2 项、`HistoryStoreTest` 3 项）；这是已记录的 Windows 存储测试限制，本次不宣称全量通过。
- Gradle 报告 `local.properties` 中旧 `sdk.dir` 路径不存在，但使用当前 Android SDK 环境完成构建；没有修改该本机配置。

## 设备验收边界

按用户要求，本轮没有继续通过 ADB 操作设备。安装专用 Intent 在目标电视上的系统安装器表现、无安装权限时文件保存以及文件管理器手动安装，仍由用户实际验收。自动化测试和线上字节核验不替代设备结论。
