# v0.0.6 发布记录：OTA 安装器与遥控器焦点修复（同名重发）

发布日期：2026-10-11 17:56（Asia/Shanghai）

版本：TVBox4.1+ / `0.0.6` / versionCode `7`（重发；首发 code6 已替换）

兼容范围：Android 4.1+ / minSdk 16，targetSdk 28

状态：已重新发布并设为 GitHub Latest；v0.0.5 保留。未通过 ADB 复测目标投影设备。

本次保留用户可见版本名和 Release 标签 `v0.0.6`，只递增内部版本码至 7。原因是 OTA 只在远端 `versionCode` 大于已安装版本时提示；这样现有 `0.0.6/code6` 安装才能收到本次遥控器焦点修复。原 code6 Release 与标签已删除并替换。

## 更新内容

- OTA APK 改用安装专用 Intent，避免通用 `ACTION_VIEW` 把安装请求交给“打开方式”选择器中的无关应用。
- 缺少“安装未知应用”权限时提供“保存”选项，把已经完成大小/SHA-256 校验的 APK 复制到公共 `Download/TVBox/`，供用户手动安装。
- Android 10+ 使用 MediaStore；Android 4.1–9 使用公共下载目录，并按系统版本处理旧式存储权限。保存不删除应用内下载源文件。
- 设置页控件设置显式四向焦点邻居，避免遥控器方向下键按布局几何位置跳项；设置页隐藏/销毁时清理顶部设置入口的焦点链接。
- 沿用既有发布证书；首发 code6 已被 code7 替代，现有 code6 和 v0.0.5 安装能够发现 OTA 更新。v0.0.5 Release 未修改。
