# 05 UI 与遥控器焦点规则

> 当前实现以 [13-当前版本基线与验收清单.md](13-当前版本基线与验收清单.md) 为准：首页为当前 MacCMS 视频源；直播入口暂时隐藏。文中上游 v1.3.6 信息仅作为历史设计参考。

## 1. 设计原则

- 电视优先：用户在约 3 米距离用方向键、确认键和返回键完成全部核心流程。
- 焦点就是状态：任何时刻都必须有且只有一个明确的主要焦点。
- 深色大屏：近黑背景、深灰卡片、活力绿强调色，避免大面积高亮白色。
- 可读优先：默认字号、行高和控件热区必须适合 720p 老盒子；文本不得依赖细字重。
- 稳定优先：API 19 禁用昂贵模糊、实时阴影和大面积复杂动画。
- 触摸兼容：手机可以点击和手势操作，但不能破坏遥控器焦点路径。

## 2. 基准视觉

建议色彩：

- 页面背景：`#0B0C0F`
- 卡片背景：`#17191D`
- 次级背景：`#22252A`
- 主文字：`#F4F5F7`
- 次文字：`#A9ADB5`
- 强调/焦点：`#00D4AA`
- 错误：`#FF6B6B`

焦点态至少同时包含两种信号：强调色描边 + 轻度放大或背景变化。不要只靠颜色区分；720p 下描边建议 2 至 3dp，缩放建议 1.04 至 1.07，动画 100 至 160ms，低性能模式可直接无动画切换。

## 3. 安全区与布局

- 以 1280×720 作为首要基准，同时验证 1920×1080。
- 四周保留至少 32dp 安全区，标题和关键按钮不贴边。
- 海报卡使用约 2:3，比率统一；直播房间封面使用 16:9。
- 720p 首屏建议 5 至 6 列海报；字体增大时自动降列，不压缩文字。
- 列表和网格必须允许内容滚动到焦点可见范围，不能让焦点停在屏幕外。
- 图片加载前显示固定尺寸占位，避免布局跳动导致焦点漂移。

## 4. 页面结构

### 4.1 默认主题首页

顶部可见入口顺序固定：

1. 历史
2. 搜索
3. 推荐
4. 设置

电视/平台直播保持隐藏，数字键 4/5 不绑定导航。

下方为当前视频源父分类/子分类选择和海报网格。第一次进入首页焦点落在第一个内容入口或第一个可用海报，规则必须稳定。

### 4.2 影院主题首页

- 左侧图标导航，右侧 Hero + 内容行/网格。
- 左侧导航与内容区有清楚分界。
- Hero 的“播放/详情”按钮可被上下左右稳定到达。
- 切换主题后尽量映射到同语义入口，不把焦点丢到根 View。

### 4.3 其他页面

- 搜索：输入区、搜索按钮、状态文案、结果网格。
- 详情：海报/元信息、简介、线路列表、选集网格、播放入口。
- 历史：历史卡片、进度、集数、清空入口。
- 直播：全屏画面 + 可隐藏左侧频道列表 + 顶部临时提示。
- 平台直播：平台、一级分类、二级分类、房间四级状态，返回逐级退栈。
- 设置：分区卡片，开关和值均可聚焦；二维码弹窗关闭后焦点回到触发按钮。

## 5. 焦点硬规则

- 所有可点击控件必须 `focusable=true` 且有可见焦点态。
- 纯装饰、不可用按钮和加载骨架不得获取焦点。
- RecyclerView 复用后不能把旧 item 的 selected/focused 样式带到新 item。
- 页面首次显示、数据首次到达、分页追加、错误重试、弹窗关闭和返回页面时都要定义焦点目标。
- 数据刷新时优先按稳定 ID 恢复焦点；ID 不存在才选择邻近项或第一个可用项。
- 不得在每次 `onBind` 或状态刷新时无条件 `requestFocus()`，避免抢走用户当前焦点。
- 横向列表到边界时不应跳到不可预测区域；必要时显式设置 `nextFocusLeft/Right/Up/Down`。
- 弹窗打开时焦点被限制在弹窗内；关闭时恢复触发控件。
- 返回播放器/详情/列表后恢复滚动位置和语义焦点。

## 6. 遥控器按键

### 6.1 全局

| 按键 | 行为 |
| --- | --- |
| DPAD 上下左右 | 移动焦点或在直播页执行已定义切换 |
| CENTER / ENTER | 激活当前焦点 |
| BACK | 关闭弹窗、逐级返回；首页再次返回可提示退出 |
| MENU | 播放器切换倍速或打开轻量设置 |
| MEDIA_PLAY_PAUSE | 播放/暂停 |

对 `ACTION_DOWN` 和长按重复事件要去抖。一次按键只触发一次页面动作，不能同时被 Activity 和子 View 消费。

### 6.2 首页数字键

- `1` 历史、`2` 搜索、`3` 推荐、`6` 设置；`4` 和 `5` 暂停使用。
- 同时兼容 `KEYCODE_1` 与 `KEYCODE_NUMPAD_1` 等映射。

### 6.3 点播播放器

- 确认/播放暂停：播放或暂停，并显示控制层。
- 左/右：控制层可见时快退/快进；不可见时先显示控制层，行为保持一致。
- 数字 `1`/媒体上一首：上一集。
- 数字 `3`/媒体下一首：下一集。
- 菜单键：按固定序列切换倍速并显示当前值。
- 返回：退出播放器，回到详情并恢复选集焦点。

### 6.4 电视直播

- 左/右：上一/下一频道，首尾循环。
- 上/下：当前频道上一/下一线路，首尾循环。
- 确认/播放暂停：显示频道列表。
- 数字键：累积频道号，短延迟后跳台；输入状态可见。

## 7. 手机触摸兼容

点播播放器保留：

- 单击显示/隐藏控制层。
- 左/中/右区域双击：快退 10 秒、播放/暂停、快进 10 秒。
- 横向滑动调整进度。
- 左半屏纵向滑动亮度，右半屏纵向滑动媒体音量。
- 长按临时 2 倍速，抬起恢复。

直播播放器保留：单击显示频道列表，双击左右区域切换频道。触摸手势必须设置阈值，不能把轻微移动同时识别为点击与滑动。

## 8. 字体与无障碍

- 三档字体：正常 `1.00`、大 `1.18`、超大 `1.36`。
- 字体放大时不仅放大文字，还调整卡片高度、行间距、按钮 padding 和网格列数。
- 重要图标提供中文 contentDescription；纯装饰图标不重复朗读。
- 焦点、选中、推荐、失败不能只用颜色表达，要有边框、文字或图标辅助。
- 长简介限制行数并提供可聚焦“展开/收起”，不让页面无限增高。

## 9. UI 验收

- 只用遥控器可完成：首页 → 搜索 → 详情 → 选集 → 播放 → 返回 → 历史。
- 每个弹窗可打开、操作、关闭，关闭后焦点回原按钮。
- 列表分页追加后当前焦点不跳到顶部。
- 网络错误显示重试按钮，重试按钮可聚焦。
- 正常/大/超大字体在 720p 不重叠、不裁切关键操作。
- 影院主题和默认主题分别完成全流程焦点录屏。
