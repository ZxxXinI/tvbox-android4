# TVBox Android 4.4+ 规则文档集

这组文档用于指导另一个模型，在不直接修改主工程 `app/` 的前提下，实现一款功能与当前 TVBox 主项目一致、最低支持 Android 4.4（API 19）的独立应用。

当前功能基线来自仓库根目录的 TVBox v1.3.6。目标是“产品行为等价”，不是把现有 Compose/Media3 源码原样复制后只修改 `minSdk`。Android 4.4 版本必须替换不兼容的 UI、播放器和依赖，同时保留页面流程、遥控器操作、数据规则和容错语义。

## 使用方式

1. 首次交给模型时，同时提供本目录全部文档，并要求先阅读 `00`、`01`、`02`。
2. 每轮只实施 `11-分阶段实施任务单.md` 中一个 Gate。
3. 每个 Gate 必须先报告将修改的文件和验收命令，完成后给出真实输出；不允许只说“应该可以”。
4. API 19 模拟器只能做安装与基本回归，播放器和遥控器最终结论必须来自真实 Android 4.4 盒子。
5. 任何上游接口、直播源、平台 Cookie 和 AI Key 都属于外部配置，不得写入日志、截图或公开仓库。

## 完成定义

只有同时满足以下条件，才可声称“支持 Android 4.4+”：

- APK 的 `minSdkVersion` 为 19，且 API 19 设备成功安装、冷启动和完成核心点播播放。
- 依赖树中不存在 `minSdk > 19` 的运行时库，未通过 `tools:overrideLibrary` 强行绕过。
- 所有高版本 API 都有版本判断或 API 19 回退路径。
- 遥控器全流程不存在焦点丢失、不可达控件或返回键死路。
- H.264/AAC 的 HLS 和 MP4 在目标盒子通过；H.265、10-bit、4K 等只按实机能力声明。
- 网络失败、空数据、解析失败、播放失败和更新失败都有可见提示并可恢复。
