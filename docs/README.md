# TVBox Android 4.1+ 文档入口

本仓库 `ZxxXinI/tvbox-android4` 已是独立兼容版，源码在 `app/src/main/java/com/tvbox/android44/`。当前首页直接展示选定的 MacCMS 视频源，支持父/子分类与分页；电视及平台直播入口暂时隐藏。

2026-10-07 按用户要求将当前最低版本扩展至 Android 4.1 / API 16，兼容修改和证据以 [17-Android4.1兼容扩展.md](17-Android4.1兼容扩展.md) 为准。历史 API 19 设备结果不替代 API 16 设备验收。

先读 [13-当前版本基线与验收清单.md](13-当前版本基线与验收清单.md)，再读 [00-总规则与执行协议.md](00-总规则与执行协议.md)。`01` 至 `12` 为模块规则及历史设计，涉及上游 v1.3.6 的范围以 `13` 的当前约定覆盖。

实现、测试及剩余设备/发布验收状态见 [14-文档规划复查与待补任务.md](14-文档规划复查与待补任务.md)。本轮 P1/P2 已补齐源码与自动化；设备结果和 P3 剩余建议按通过条件记录。
