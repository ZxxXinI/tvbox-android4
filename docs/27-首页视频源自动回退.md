# 首页视频源自动回退

2026-11-20 09:07（Asia/Shanghai）。用户报告默认源不可访问时，首页只显示请求超时，希望自动切换到下一个可用源。

## 行为

- 首页优先从设置中的默认源加载。首屏失败时，按设置列表从当前源的下一项开始尝试，走到末尾后从头继续，每个不同地址最多探测一次。备用源探测只请求第一页，单次最多 8 秒，通过网络实时确认能返回影片。
- 找到有影片的备用源后，显示「首页当前使用：…（自动切换）」，分类、分页、卡片和详情对应同一个源。源的分类 ID 属于各自的接口，切换后从备用源的「全部」开始。默认源正常返回空列表时保留空态。
- 自动切换只在首页生效。设置中的默认值保留，下次启动仍优先尝试用户选的源。全部失败后显示「重试」。单独的分类表或分页请求失败时，保留当前源并提示，不会把用户正在浏览的内容换成其他源的数据。

## 实现与验收

- `HomeFragment.java` 分开维护默认源和首页实际源。取消旧请求、过滤过期回调、切换列表与分类请求，并在首页提供重试。
- `MovieRepository.java`、`AppConstants.java` 为备用源提供轻量的首页探测，使用独立超时，探测失败不触发其他功能的来源冷却。
- `strings.xml` 增加尝试进度、切换结果与错误提示。
- `NavigationStateTest.java` 使用本地模拟 HTTP 源检查失败、空备用源、继续尝试、分类隔离、全部失败与恢复默认源。

导航与数据仓库专项 34 项通过，Debug/Release Lint 和 Release 构建成功。本地测试包 `dist/TVBox4.1+-home-source-fallback-test.apk` 包含前一轮遥控器改动，版本 0.0.6 / code7，最低 API 16，v1/v2 签名证书与公开版一致。文件 2,995,763 字节，SHA-256 `7dac0c52fd56d07938bd99d956a4b90d62c9b12c50dc9c671d9a633fd4dc9a66`。

设备临时方式是到设置里手动换源。用测试包现场验收时，可将一个不可访问的自定义源设为默认，返回首页观察备用源的实际内容，再核对设置中的默认项。
