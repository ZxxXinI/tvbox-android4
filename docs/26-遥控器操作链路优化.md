# 遥控器操作链路优化

2026-11-20 08:35（Asia/Shanghai）。基于公开版 v0.0.6 / code7 的本地改动。

| 文件 | 审查发现与调整 |
| --- | --- |
| `MainActivity.java` | 实体数字键原先先于输入框处理，还会重复切页。现在编辑焦点接收数字，已接管的快捷键只在首次按下切页。推荐卡片打开搜索时记住来源，返回恢复推荐卡片；直接进入搜索仍回首页。首页退出计时在切页时清零。 |
| `SettingsFragment.java`、`fragment_settings.xml` | 固定邻接关系无法区分从哪一列经过整行按钮。方向键按可见行移动，记住每行最后使用的按钮，优先回到该按钮；左右在本行移动，跳过不可用控件。 |
| `PlayerActivity.java`、`PlayerControllerView.java` | 实体返回在按键抬起时退出播放器，控制栏显隐和错误提示不改变返回去向。错误层接管按键。换线保留播放意图，按同地址或两条线路各自唯一的同标题集保留进度；自动换线仅尝试匹配集，手动换到无法匹配的集时提示从头开始。缓冲时按钮文案跟随播放意图。 |
| `DetailActivity.java`、`activity_detail.xml`、`strings.xml` | 原来简介获得焦点就展开，挤占选集区域。保留最多三行的预览，按「展开简介」在可滚动的弹窗显示全文，关闭后恢复到入口。 |
| `NavigationStateTest.java`、`PlayerFlowTest.java` | 用按键事件与可控播放器检查数字输入、快捷键去重、推荐卡片返回、设置往返、播放器退出、换线状态和简介弹窗。 |

## 设备验收

1. 遥控器或键盘在搜索框键入 `2012`，检查仍停在输入框。移到搜索按钮，再按 `6` 进入设置。
2. 设置中分别验证「字体 → 当前视频源 → 字体」和「管理自定义源 → AI 提供方 → 管理自定义源」。切到扫码按钮后往返，检查回到扫码按钮。
3. 从推荐卡片打开搜索，从搜索结果进详情。焦点经过「展开简介」时，选集位置应稳定；按确认阅读全文，关闭后应回到该按钮。
4. 播放中分别在控制栏显示、自动隐藏、播放报错时按一次返回。检查回到详情以及选中集的焦点。再返回搜索、推荐，查看原卡片是否恢复。
5. 在有多条线路的剧集中暂停后手动换线。同一集应停在原进度；若提示没有对应集，确认新集从头开始。确认播放中的自动换线只尝试同一集。
