# 首页继续观看与手机扫码搜索

2026-11-20 09:34（Asia/Shanghai）。参考 TVBox 主版 v1.3.14 的「继续观看」与「手机扫码输入」。主版记录该扫码搜索需求由 LINUX DO 社区用户 patrickpa 提出。

## 首页继续观看

- 默认和影院主题共用一行横向卡片，最多六部，按历史更新时间顺序展示。跳过无进度、进度已达 95% 和过滤掉的条目。无符合条件的历史时隐藏整行。时长未知时显示已播放时长。
- `HomeFragment.java` 在磁盘线程读取已有历史，通过已有续播入口把原视频源、线路、集数和进度交给播放器。首页切源和首屏等待不影响历史加载。
- `PosterGridAdapter.java`、`section_home_continue.xml`、`item_home_continue.xml` 复用现有海报和稳定条目 ID。向上回顶部导航，从播放器返回时优先恢复原卡片。影院主题在历史行有内容时压缩主推区，给影片列表留出空间。

## 手机扫码搜索

- `SearchFragment.java`、`fragment_search.xml` 提供「手机扫码输入 · 菜单键」。`MainActivity.java` 仅在搜索页接管菜单键，抬起触发一次。手机和电视在可互通的同一局域网内时，扫码提交片名，电视填入关键词并执行现有多源搜索。
- `LanQrDialog.java` 复用已有二维码布局、局域网地址选择及手工地址。AI 和视频源扫码也使用该显示组件。
- `ConfigHttpServer.java` 新增独立搜索模式。搜索会话仅接收限长的关键词，使用随机令牌、5 分钟有效期和一次成功提交限制。退出搜索、关闭弹窗或切后台时关闭会话并释放端口。

## 设备验收

1. 播放一集到中途退出，回首页检查最近历史、集数和进度。点击卡片直接续播，退出后检查焦点；切换首页视频源后重复验证，确认续播仍指向历史里的片源。默认和影院主题各检查一次。
2. 在搜索页打开扫码弹窗，用手机提交中文片名。确认电视出现搜索结果、弹窗自动关闭、旧二维码失效。也可用遥控器菜单键打开，再按返回取消，确认取消后手机无法提交。
3. 测试离开搜索页、切后台、超时和手机与电视不互通的情况。后者可继续使用电视上的输入框。
