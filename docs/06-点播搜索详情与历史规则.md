# 06 点播、搜索、详情与历史规则

## 1. 首页加载

启动后按以下顺序：

1. 读取本地设置和缓存，立即渲染可用旧数据。
2. 加载豆瓣热播默认类别；成功后更新并缓存。
3. 豆瓣无缓存且失败时，加载当前 MacCMS 来源第一页。
4. 用户选择父/子分类时，只请求当前来源对应分类。
5. 滚动接近底部才加载下一页；同页请求只能有一个。

切换视频接口时必须取消旧首页/搜索/详情请求，清空不兼容的分类选择，重载新来源首页，同时保留历史数据。

## 2. 豆瓣卡片到播放详情

豆瓣条目点击流程：

```text
豆瓣标题
  → 当前 MacCMS 来源搜索同名
  → 标准化片名匹配，年份作为辅助
  → 命中后取完整详情
  → 立即显示主详情
  → 后台补充其他来源线路
```

无匹配时显示“当前视频接口未找到可播放资源”，提供“换接口”和“返回”入口，不使用豆瓣 ID 请求 MacCMS 详情。

## 3. 多来源搜索调度

- 搜索词 trim 后不能为空；新搜索增加 `requestId` 并取消上一搜索。
- 来源顺序：当前主来源固定第一；其余来源排除冷却项后按近期成功和延迟排序。
- 同时在途最多 3 条；单来源 3 秒超时。
- 每个来源完成后，在主线程增量合并结果并更新 `已完成 N/M 条线路 · 找到 X 个结果`。
- 单来源失败只增加已完成数和健康记录，不把整页置为错误。
- 所有来源完成且结果为空，才显示统一空态。
- 用户离开页面导致的取消不计失败、不显示错误。

## 4. 去重与展示

- 去重键使用规范化片名 + 年份。
- 相同作品保留主来源卡片；可记录 `availableSourceIds` 供详情补线。
- 首次出现顺序保持稳定，后续增量结果不得重新洗牌导致焦点跳动。
- 海报为空显示占位；海报失败不影响卡片点击。
- 搜索结果经过统一内容过滤。

## 5. 详情渐进补线

1. 先请求用户点击卡片所属来源的 `ids` 详情。
2. 主详情返回后立即渲染元信息、主线路和选集。
3. 其他来源以片名搜索候选，再请求最匹配候选详情。
4. 替代来源最多三条并发，单来源完整匹配流程超时 4 秒。
5. 每发现有效线路立即追加，不等待全部来源。
6. 按稳定 `lineId` 去重，追加时不能重置当前线路、选集或焦点。
7. 慢源/失败源进入 2 分钟冷却；取消不进入冷却。

详情状态必须区分：主详情加载、补线进行中、已有线路数量、完成来源数量和单独补线错误。已有可播放线路时，补线失败不得覆盖详情页为全屏错误。

## 6. 线路与选集

- 默认优先名称含 `m3u8` 且有有效选集的线路，否则选择第一个有选集线路。
- 线路按钮显示来源名和线路名，必要时显示“推荐/近期失败/较慢”。
- 切换线路时，优先按当前集标题匹配新线路；无法匹配时限制到合法索引并提示。
- 大量剧集使用 RecyclerView 网格，稳定 ID 为 `lineId + episodeIndex + title`。
- 进入详情默认聚焦“继续播放”或当前线路的历史集数；无历史则第一集。
- 补线追加后不改变用户已经选择的线路。

## 7. 历史记录

保存字段：影片 ID、来源 ID/名称、影片名、海报、类型、备注、线路索引/名称、集索引/标题/URL、进度、总时长、更新时间。

规则：

- 同一 `apiLineId + movieId` 覆盖旧记录并移到最前。
- 最大 100 条，超出删除最旧记录。
- 播放 READY 后开始节流保存；每 10 至 15 秒、暂停、切集、换线和退出时保存。
- 进度百分比仅在时长与位置均有效时计算，并限制 0 至 100。
- 片尾自然播放完成时可把当前集标为完成；进入下一集后保存新集状态。
- 历史页读取时再次执行内容过滤，损坏条目单独丢弃。
- 清空历史有二次确认，完成后焦点回到空态返回按钮。

## 8. 历史恢复

恢复顺序：

1. 根据历史的来源 ID 和影片 ID 重新取详情。
2. 找到同名线路和同标题集；索引只作为第二选择。
3. 使用最新地址创建播放器。
4. 仅在重新获取失败且历史 URL 仍是合法 `http/https` 时，提示用户并允许临时尝试旧地址。
5. 进度距离片尾过近时从头或下一集开始，具体阈值集中定义。

## 9. 空态与错误文案

- 首页失败：“内容加载失败，请检查网络或切换视频接口。”
- 搜索为空：“没有找到相关影片，可以换个关键词或视频接口。”
- 主详情失败：“影片详情加载失败，请重试或返回搜索结果。”
- 补线失败但有主线路：“其他线路暂未加载完成，当前线路仍可播放。”
- 历史失效：“原播放线路可能已更新，正在重新查找资源。”

不得把域名、Key、堆栈或完整异常显示给普通用户。

## 10. 单元测试最低集合

- 播放串中 `$$$`、`#`、`$` 的正常/错位/空值/Markdown URL。
- HTML 清理与实体替换。
- 片名规范化不误合并不同季。
- 多来源增量合并、主来源优先和稳定顺序。
- 并发上限 3、3 秒超时、取消不记失败。
- 详情追加线路不重置选择。
- 历史覆盖、排序、上限、损坏 JSON 回退和进度计算。
