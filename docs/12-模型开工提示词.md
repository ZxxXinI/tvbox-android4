# 12 模型开工提示词

> 当前实现以 [13-当前版本基线与验收清单.md](13-当前版本基线与验收清单.md) 为准：首页为当前 MacCMS 视频源；直播入口暂时隐藏。文中上游 v1.3.6 信息仅作为历史设计参考。

下面的文本可直接复制给负责开发的模型。使用时请同时把本目录全部规则文档加入上下文，并把“本轮 Gate”替换成实际编号。

## 总提示词

```text
你要在一个独立目录中实现 TVBox Android 4.4+ 应用。产品范围以 docs/13-当前版本基线与验收清单.md 为准；首页使用当前视频源，直播入口保持隐藏，最低运行系统固定为 Android 4.4 / API 19。

开始前必须完整阅读 docs/README.md、docs/13-当前版本基线与验收清单.md、00-总规则与执行协议.md、01-产品目标与功能基线.md、02-兼容性与技术选型规则.md，以及本轮相关模块文档和 11-分阶段实施任务单.md。

硬约束：
1. 本仓库已是独立兼容版，可修改本仓库 app/；保留独立包名和 Gradle，不依赖上游现代版模块。
2. minSdk 必须为 19，不得提高，不得用 tools:overrideLibrary 绕过。
3. UI 使用 XML + 传统 Views，不使用 Compose/Compose for TV。
4. 播放器使用支持 API 19 的 com.google.android.exoplayer2，不使用当前 Media3。
5. 不关闭 HTTPS 证书校验，不泄露 API Key、Cookie、签名口令或私有地址。
6. 网络/磁盘/JSON/哈希全部离开主线程，页面销毁时取消请求并释放播放器/端口。
7. 本轮只完成 Gate {编号和名称}，不得提前堆叠后续 Gate。
8. 既有中文 Markdown 保留 BOM；源码、构建脚本和 YAML 使用 UTF-8 无 BOM；完成后回读检查 U+FFFD。
9. 每次变更更新 AI_DEV_LOG.md，并输出变更报告。

修改前先回答：
- 本轮目标和非目标。
- 将读取、创建、修改的文件。
- API 19 风险点。
- 自动化命令和实机验收步骤。

完成后必须给出：
- 实际修改文件和关键决定。
- 实际执行的命令及通过/失败结果，不得伪造。
- API 19 已验证、仅静态验证、未验证三类清单。
- 已知风险、回滚方式和下一 Gate 是否允许开始。

如果缺少设备、SDK、接口授权或密钥，只完成不依赖它的部分，并把该项标为未验证；不要把“构建成功”写成“Android 4.4 已适配完成”。
```

## 单轮任务模板

```text
本轮只执行 Gate {X}：{名称}。

输入资料：
- Android4.4 规则文档全集
- 当前主工程只读参考
- 本轮可用设备/接口：{填写}

必须交付：
- {本 Gate 的文件或功能}
- 单元测试/构建命令
- Gate X 验收报告
- AI_DEV_LOG.md 更新

明确禁止：
- 依赖上游现代版 app/ 模块
- 实施 Gate {X+1} 及以后内容
- 用高版本设备结果代替 API 19 结论
- 将外部凭据写入源码或日志
```

## 审查提示词

```text
请只审查当前 Gate，不直接扩大实现范围。逐项核对：
1. minSdk=19 是否真实，依赖树是否存在 API 21+ 库。
2. 是否误用了 Compose、Media3、新系统 API 或 tools:overrideLibrary。
3. 网络/磁盘是否离开主线程，生命周期是否释放资源。
4. 遥控器焦点是否有首次、刷新、返回、弹窗恢复规则。
5. 错误、空数据、超时、取消是否分开处理。
6. 自动化输出和 API 19 运行证据是否足够。
7. 是否泄露 Key、Cookie、签名和私有 URL。

只报告可复现的问题，按严重度排序，并指出具体文件和修复验收方法。没有证据的“应该兼容”不能算通过。
```

## 上下文不足时的处理

如果模型上下文窗口不足，优先保留：

1. `00-总规则与执行协议.md`
2. `02-兼容性与技术选型规则.md`
3. 当前 Gate 在 `11-分阶段实施任务单.md` 中的内容
4. 当前 Gate 对应的模块规则文档
5. 上一 Gate 验收报告

不要用 README 的简短摘要替代模块规则中的阈值、失败路径和验收条件。
