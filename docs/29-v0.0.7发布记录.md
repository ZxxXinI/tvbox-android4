# TVBox4.1+ v0.0.7 发布记录

2026-11-21 09:09（Asia/Shanghai）公开并设为 Latest。版本名 `0.0.7`，内部版本码 `8`，最低 Android 4.1 / API 16。

## 发布内容

- 首页继续观看与手机扫码搜索。继续观看使用历史中的来源、集数和进度。手机提交片名后电视自动搜索。扫码搜索需求参考 TVBox 主版，感谢 LINUX DO 用户 patrickpa。
- 默认视频源失败后自动探测备用源，首页显示实际使用的来源。
- 优化遥控器返回、设置按行导航、数字输入、换线和详情简介。
- 修复分类、线路及选集在同时选中和聚焦时文字过暗。

## 构建和签名

- 发布源码为 `0b34020449bd4b344d93815754eee093dc111c16`，标签 `v0.0.7` 与 APK 内构建来源一致。
- APK 为 3,002,455 字节，SHA-256 为 `63b124d8db2692fe07c0c417a7719cd838631a5bf3014c14226db2e272aafeec`。包名 `com.tvbox.android44`，targetSdk 28，v1/v2 签名有效。
- 发布前比对旧 v0.0.6/code7 的公开 APK，沿用同一签名证书。code8 满足 OTA 与系统覆盖安装的版本条件。
- Release 构建、Lint 和 16 项发布工具测试通过。Windows 全量 Debug 回归 428 项，423 项通过，已知存储用例 5 项失败（HealthStore 2 项、HistoryStore 3 项）。投影安装与实体遥控器表现留待设备验收。
- [GitHub Actions](https://github.com/ZxxXinI/tvbox-android4/actions/runs/44847922451) 的 Linux Debug/Release 全量测试、Lint、构建与发布校验全部通过。
