# 01 产品目标与功能基线

> 当前实现以 [13-当前版本基线与验收清单.md](13-当前版本基线与验收清单.md) 为准：首页为当前 MacCMS 视频源；直播入口暂时隐藏。文中上游 v1.3.6 信息仅作为历史设计参考。

## 1. 产品目标

实现一款横屏、遥控器优先、同时保留手机触摸能力的 TVBox 应用，最低支持 Android 4.4（API 19）。当前独立兼容版为 v0.0.1（versionCode=1），以 `13` 的产品范围为准，但运行时必须适配低内存、低性能、旧 Web/TLS 栈和不完整遥控器按键映射的电视盒子。

## 2. 用户主流程

```text
启动
  ├─ 当前视频源首页/分类 → 影片详情 → 线路/选集 → 播放器
  ├─ 搜索 → 多来源增量结果 → 详情 → 播放器
  ├─ 推荐 → AI 推荐条目 → 资源站搜索 → 详情 → 播放器
  ├─ 历史 → 恢复影片、线路、集数和进度
  └─ 设置 → 主题/字体/接口/AI/播放管家/OTA
```

任何页面都必须有明确加载态、空态、错误态、重试入口和返回路径。

## 3. 最终功能清单

### 3.1 启动与首页

- 同时声明普通 `LAUNCHER` 与电视 `LEANBACK_LAUNCHER` 入口，`android.software.leanback` 和触摸屏均不得设为必需。
- 默认横屏，恢复上次主题、字体、视频接口、播放管家和更新设置。
- 默认首页直接展示当前 MacCMS 来源内容，分类表与内容分别加载；不请求豆瓣首页。
- 支持来源首页、父分类、子分类、海报网格、备注、分页加载和重试；父分类“全部”聚合其子分类。
- 卡片携带来源 ID 与影片 ID，点击后获取该来源完整详情，再渐进补充替代线路。
- 默认主题保留历史、搜索、推荐、设置四个入口；影院主题提供左侧导航和当前源内容 Hero。电视/平台直播入口保持隐藏。

### 3.2 搜索与详情

- 搜索以当前视频来源为最高优先级，最多三条来源同时请求。
- 任一来源返回后立即增量展示，不等待最慢来源。
- 按规范化片名和年份去重，主来源结果优先。
- 详情先显示主来源，再在后台渐进补齐其他来源的可播放线路。
- 展示海报、片名、分类、年份、地区、语言、演员、导演、时长、简介、线路和选集。
- 选集必须支持大量剧集滚动，并在返回详情时恢复选择和焦点。

### 3.3 播放与历史

- 支持 HLS/m3u8 和普通 MP4；首要实机格式为 H.264 + AAC。
- 支持播放/暂停、进度、快进/快退、上一集、下一集、倍速、自动下一集和手动换线。
- 记录影片、来源、线路、集数、播放 URL、进度、总时长和更新时间，最多 100 条。
- 从历史恢复时先尝试重新获取详情和当前线路；历史中的 URL 只作为短期回退，不能假设永久有效。
- 播放失败、持续缓冲或频繁卡顿时由播放管家记录健康度并按规则换线。
- 竖屏视频完整显示，不拉伸不裁切；电视保持横屏并允许左右黑边。

### 3.4 电视直播

- 从可配置 IPTV 文本地址加载并解析分组。
- 仅解析 `分组名,#genre#` 之后的合法频道行。
- 同组同名频道合并线路、重复 URL 去重，不同组同名频道保持独立。
- 左右切频道、上下切线路、确认键显示频道列表、数字键输入频道号。
- 播放错误、持续缓冲或播放位置停滞时自动尝试下一条线路。

### 3.5 平台直播（入口隐藏，后续独立验收）

- 客户端支持斗鱼、虎牙、哔哩哔哩、抖音、快手的统一浏览流程。
- 只调用既有 `platform_live_server`：平台 → 一级分类 → 二级分类 → 房间 → 解析临时播放地址。
- 服务端凭据和平台 Cookie 永远不进入 APK。
- 优先最高画质；同画质多个 CDN 候选失败时依次恢复，必要时强制刷新临时地址。

### 3.6 AI 推荐与配置

- 支持 OpenAI Chat Completions 兼容格式的 Agnes、DeepSeek、SiliconFlow、Qwen 配置。
- 用户输入自然语言需求后，AI 返回 6 至 8 个结构化推荐；点击条目后按 `searchKeyword` 搜资源站。
- 支持快捷推荐词和“换一批”。语音识别为可降级能力，系统没有语音服务时仍可文字输入。
- 电视端通过局域网临时 HTTP 页面和二维码配置模型、API Key、自定义 MacCMS 接口。
- 配置会话只在前台临时存在，完成或离开页面后必须关闭监听端口。

### 3.7 设置与 OTA

- 默认主题/影院主题；正常/大/超大三档字体。
- 选择内置视频接口并新增自定义 MacCMS 接口。
- 选择 AI 提供方、模型和 API Key。
- 播放管家自动换线开关、线路统计查看和清空。
- 启动检查更新开关、手动检查、更新说明、下载进度、SHA-256 校验和系统安装器。
- 只在用户实际点击下载/安装时引导未知来源安装权限，启动时不得强制跳权限页。

## 4. 当前基准数据

- 本仓库版本：`0.0.1`，`versionCode=1`；上游 `1.3.6/10306` 不用于本包的 OTA 版本比较。
- 当前内置视频来源名称：量子、如意、360、牛牛、鸭鸭、红牛、索尼、非凡。
- 当前首页分页与 pageCount 来自 MacCMS 响应；豆瓣缓存仅保留为历史模块，不驱动当前首页。
- 搜索最大并行来源：3；单来源搜索超时 3 秒。
- 详情补线单来源超时：4 秒。
- 列表/搜索内存缓存：5 分钟、最多 80 条；详情缓存：30 分钟、最多 60 条。
- 来源失败冷却：2 分钟。
- 播放健康记录：30 天、最多 300 条；历史最多 100 条。

这些数值是行为基线。Android 4.4 实机如果出现明确资源瓶颈，可降低图片并发和网格预加载，但不得改变搜索并发上限、去重语义和渐进展示语义，除非有测试证据并记录变更。

## 5. 明确非目标

- 不实现账号、会员、云同步、弹幕、下载缓存、投屏或 DRM 绕过。
- 不把第三方视频或直播内容打包进 APK。
- 不承诺旧盒子硬件不支持的 H.265、AV1、10-bit、HDR、4K、高码率或特殊音频格式。
- 不在客户端实现五个平台的网页签名、Cookie 抓取或反爬逻辑。
- 不通过 WebView 重做完整 UI；WebView 仅可用于非常有限的配置页替代方案，默认仍使用外部手机浏览器访问局域网配置页。

## 6. 产品验收口径

“功能完成”以可操作结果判断，不以类名或页面外观判断。示例：

- 搜索完成：至少两个来源有结果时，用户能先看到首个来源结果，后续结果继续加入且不重复。
- 详情完成：主详情先显示，替代线路逐步增加，期间用户可立即播放已有线路。
- 直播完成：真实频道能出画出声，遥控器切台/切线有效，坏线可恢复。
- AI 完成：有效配置能得到结构化推荐，错误 Key 不崩溃且不泄露 Key。
- OTA 完成：清单比较、下载、大小/哈希校验、安装权限分支和安装器调起均验证。
